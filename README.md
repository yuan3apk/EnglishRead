# EnglishRead

一个「读英文书」的 Android App：导入 EPUB / TXT，点单词看本地释义，点「段」看这一句的中文译文，还能听书。

## 能做什么

- **导入**：本地文件（SAF）或 URL 直链，EPUB2 / EPUB3 / TXT；TXT 自动识别 BOM / UTF-8 / GB18030。 。
- **查词**：内置 ECDICT 裁剪词库（8 万词 + 5.6 万变形反查），**完全离线**，毫秒级；点词弹卡，长按加生词本。
- **段译文**：点该句下面的「段」，只把这**一句**发给AI 兼容接口，译文内联展开并永久缓存。
- **听书**：系统 TTS，逐词高亮。
- **生词本**：记录命中处的原句，按书筛选、只看未掌握、标记已掌握。
